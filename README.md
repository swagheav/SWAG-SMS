## 🔍 Overview
**SWAG-SMS** is a powerful **command-line SMS testing utility** built for **security researchers**, **educators**, and **ethical hackers** — **made in 2026**. Its **core purpose** is to improve **cybersecurity awareness** and **network resilience** by providing a controlled testing environment.

The tool features a stylish terminal interface with ASCII art branding, animated loading spinners, live progress bars, and real-time statistics. It is a **lightweight, single-file Python script** that runs on **any Python IDE** — including Termux, VS Code, PyCharm, IDLE, Sublime Text, Thonny, and more.

## 🚀 Installation

```bash
# Clone the repository
git clone https://github.com/swagheav/SWAG-SMS.git

# Enter project directory
cd SWAG-SMS

# Install Python dependencies
pip install requests

# Run the tool
python SWAG.py
```

> 💡 **No terminal? No problem.** Just open `SWAG.py` in any Python IDE (VS Code, PyCharm, IDLE, Thonny, etc.) and press **Run** ▶️.

## 📖 Usage

```bash
# Start SWAG-SMS
python SWAG.py
```

**Steps:**

1. Enter the **activation code** when prompted → `swag`
2. Enter SMS details:
   · **Country Code** → e.g., `1` (USA), `20` (Egypt)

   · **Target Number** → Without country code

   · **Number of SMS** → Range: 1 - 10000
3. Accept the legal disclaimer by typing `OK`
4. Monitor the real-time dashboard for delivery stats
